# Structured SQL Exam Preparation

Practical, exam-oriented MySQL study repository for **Structured and Unstructured Data — I M.Sc. Data Science**.

This repository combines the Classroom practical exercises with the separate exam-topic preparation material.

## Exact Exercise Sequence

| Exercise | Topic |
|---|---|
| 1 | Database, CRUD, DDL, CTAS, CTE, Temporary Table, LIKE |
| 2 | String Functions |
| 3 | String Manipulation |
| 4 | User Defined Function (UDF) |
| 5 | Aggregate Functions |
| 6 | GROUP BY, HAVING, Statistics, CASE |
| 7 | Subqueries |
| 8 | JOIN |
| 9 | REGEXP |
| 10 | Partition |
| 11 | Window Functions |
| 12 | Indexing |

> Ex.No. 5 and Ex.No. 6 were posted together in Classroom as `Ex.No: 5, Ex.No:6`; they are separated here according to the requested exercise numbering.
