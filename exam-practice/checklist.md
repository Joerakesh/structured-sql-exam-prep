# Structured SQL Exam Checklist

| # | Exam Topic | Coverage |
|---|---|---|
| 1 | Joins | INNER, LEFT, RIGHT, SELF, multi-table, FULL OUTER concept with UNION |
| 2 | Subqueries | IN, EXISTS, NOT EXISTS, scalar, correlated, ANY, ALL |
| 3 | Normalisation | 1NF, 2NF, 3NF, BCNF, FDs, candidate keys |
| 4 | Views | CREATE VIEW, JOIN view, inspect, DROP, updateability |
| 5 | Indexing | EXPLAIN, single-column, UNIQUE concept, composite index |
| 6 | REGEXP | ^, $, |, [], +, ., REGEXP_SUBSTR, REGEXP_REPLACE |
| 7 | Partition | LIST COLUMNS, RANGE/HASH/KEY theory |
| 8 | Window Functions | ROW_NUMBER, RANK, DENSE_RANK, PERCENT_RANK, NTILE, LAG, LEAD, FIRST_VALUE, LAST_VALUE, NTH_VALUE, SUM, AVG, COUNT |
| 9 | BCNF | FD identification, superkey test, violation, decomposition, reconstruction |
